# MTDD AI — Brand Asset Library (PNG)

Bộ tài nguyên nhận diện thương hiệu dạng hình ảnh **PNG chất lượng cao** của **MTDD AI**, được kết xuất trực tiếp theo thông số chuẩn từ text logo hiện tại trên giao diện hệ thống:
- Phông chữ: **Inter Extra Bold (800)**, letter-spacing: `-0.03em`.
- Huy hiệu AI: **Inter Bold (700)**, chữ trắng trên nền xanh primary (`#2563eb`), bo góc chuẩn.
- Khử răng cưa: Thu nhỏ từ bản gốc chuẩn master 4K (3840x960) và 2K (2048x2048) qua bộ lọc **Lanczos3** sắc nét tuyệt đối ở mọi kích thước.

Tất cả các tệp đều được lưu đồng bộ tại 2 thư mục:
1. `assets/brand/` (Kho lưu trữ source code / tài nguyên gốc của dự án).
2. `apps/web/public/brand/` (Thư mục tĩnh của web, có thể xem và tải trực tiếp từ trình duyệt qua đường dẫn `https://video.mtdd.io.vn/brand/<tên-file>`).

## 2. Biểu tượng vuông / Avatar / App Icon (Square Icons)

Tỷ lệ 1:1 hình vuông chuẩn cho ảnh đại diện đại lý / mạng xã hội (Facebook, YouTube, TikTok, Telegram), ứng dụng di động, PWA và favicon trình duyệt.
Biểu tượng gồm chữ viết tắt **M** cùng huy hiệu nhỏ **AI** ở góc phải dưới.

Các kích thước có sẵn cho từng phong cách:
`2048x2048`, `1024x1024`, `512x512`, `256x256`, `128x128`, `64x64`, `32x32`, `16x16`.

1. **Icon Nền Xanh Thương Hiệu (Blue Primary `#2563eb`)**:
   - `mtdd-ai-icon-blue-<size>.png`
   - Phù hợp: Avatar mạng xã hội nổi bật, app icon, PWA icon.

2. **Icon Nền Đen Tối (Dark Theme `#101113`)**:
   - `mtdd-ai-icon-dark-<size>.png`
   - Phù hợp: Dark mode avatar, app icon phong cách chuyên nghiệp, hiện đại.

3. **Icon Nền Trắng Sáng (Light Theme `#ffffff`)**:
   - `mtdd-ai-icon-light-<size>.png`
   - Phù hợp: Tài liệu văn phòng, avatar trên nền sáng.

4. **Icon Nền Trong Suốt (Transparent)**:
   - `mtdd-ai-icon-transparent-<size>.png`
   - Phù hợp: Chèn vào các bố cục tự do mà không bị che khuất nền.

## 3. Favicon & Web App Icons

Ứng dụng web được cấu hình đồng bộ favicon qua các chuẩn sau:
- **Favicon nhúng bundle (`FAVICON`)**: Base64 data URI được nướng trực tiếp vào bundle qua `apps/web/src/lib/brand.ts` để hiển thị tức thì không phụ thuộc network.
- **`favicon.ico` chuẩn đa phân giải**: File `apps/web/public/favicon.ico` chứa đồng thời 3 kích thước 16x16, 32x32 và 48x48 cho mọi trình duyệt và bookmark.
- **`favicon.png`**: `apps/web/public/brand/favicon.png` (64x64) cho các trình duyệt hiện đại.
- **Apple Touch Icon**: `apps/web/public/brand/mtdd-ai-icon-blue-512x512.png` cho màn hình chính iOS/iPadOS và Android PWA.

## 4. Cách tái tạo hoặc mở rộng kích thước mới

Nếu trong tương lai cần kết xuất thêm kích thước hoặc định dạng khác, chạy lệnh:
```bash
node scripts/generate-brand-pngs.mjs
```
Script này tự động sử dụng Headless Chrome và thư viện `sharp` để xuất tất cả các biến thể với độ phân giải và chất lượng cao nhất.
